MyNotePAPILLON METHOD

Comme Papillon,
mais en web.

Papillon utilise un WebView qui intercepte le login Pronote. MyNote fait pareil en web : on ouvre Pronote dans un onglet, tu te connectes via EduConnect, et on récupère ton token automatiquement.

Comment Papillon fait pour Toutatice :
1. Charge InfoMobileApp.json → récupère jetonCAS
2. Set cookies validationAppliMobile + uuid
3. Charge mobile.eleve.html?fd=1 dans WebView
4. User se connecte via EduConnect dans WebView
5. Hook window.loginState → intercepte login + mdp
6. loginToken avec pawnote → session réelle
MyNote web fait pareil :
- Proxy /ent/proxy qui injecte les hooks Papillon
- Iframe qui charge Pronote
- PostMessage loginState → /api/ent-callback → vraies données
