Connexion directe Pronote via Pawnote. Si ton lycée utilise ENT Toutatice, utilise le QR Code (méthode officielle qui contourne EduConnect).

⚠️ Si tu as "page n'existe pas" :
1. Ton lien pronote:// ne s'ouvre pas dans le navigateur (normal). Il faut le coller dans MyNote.
2. Le QR expire après 10 min ! Génère un nouveau QR à chaque tentative.
3. Ton Pronote peut bloquer Render (IP datacenter). Dans ce cas utilise login direct avec identifiants Pronote fournis par le collège.

Connexion Pronote

3 méthodes • Données réelles uniquement

Comment récupérer le QR Code (2 min) :
1. Ouvre toutatice.fr dans un nouvel onglet → Connecte-toi via EduConnect → Va dans Pronote
2. Dans Pronote: Clique ton prénom en haut à droite → Informations personnelles → Compte → QR Code
3. Clique "Générer QR Code" → tu vois un gros QR + 4 chiffres PIN en dessous → NOTE LE PIN !
4. Sur PC: Clic droit sur QR → Inspecter → cherche pronote://... → copie TOUT
OU avec téléphone: Scanne le QR avec appareil photo → copie le lien pronote://?url=...&login=...&jeton=...
Login direct Pronote : Utilise les identifiants Pronote que ton collège t'a donnés (pas EduConnect). Si tu n'en as pas, utilise QR Code.
Ouvre Toutatice dans un nouvel onglet, connecte-toi, va dans Pronote, puis génère un QR Code pour revenir ici.

Pourquoi pas de retour auto ? Toutatice n'autorise que Pronote comme service CAS, pas MyNote. C'est bloqué par l'académie.
MyNote utilise Pawnote (API Pronote officielle non-officielle). Aucun mot de passe stocké. Données réelles uniquement.
